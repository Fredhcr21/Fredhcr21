## Diseño con intención. Desarrollo de principio a fin.

Soy desarrollador **Full Stack**. Mi enfoque conecta la experiencia del usuario con la lógica de negocio, las bases de datos y las integraciones que dan vida a un producto.

- **Interfaces:** aplicaciones web claras, adaptables y cuidadas en cada interacción.
- **Backend:** servicios, APIs, autenticación y persistencia de datos.
- **Productos:** comercio electrónico, operaciones en tiempo real y plataformas de reservación.
- **Forma de trabajar:** código legible, colaboración y metodologías ágiles.

Plataforma de gestión de traslados con monitoreo GPS, mapas interactivos, geocercas y asignación de vehículos.

### 02 / Ma Fleur
**Comercio digital**

Plataforma para florerías con catálogo, administración de productos, gestión de pedidos y autenticación, orientada a una evolución SaaS.

`React` `JavaScript` `Vite` `PHP` `Symfony` `MySQL` `Doctrine ORM`
